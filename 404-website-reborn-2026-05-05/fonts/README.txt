Druk Wide Bold font files go here.

Expected filenames (CSS @font-face references both):
  druk-wide-bold.woff2   (preferred)
  druk-wide-bold.woff    (optional fallback)

Druk is a commercial font from Commercial Type:
  https://commercialtype.com/catalog/druk

Until the file is dropped in, the site falls back to Archivo Black
(loaded from Google Fonts), which is the closest free look-alike.

No code changes needed — just place the file here and reload.
